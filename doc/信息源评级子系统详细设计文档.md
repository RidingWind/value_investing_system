# 信息源评级子系统详细设计文档

---

## 1. 模块定位与职责

- 自动对采集到的每一条公告、新闻、研报评定可靠性等级（A/B/C/D）
- 支持人工干预修改评级，记录完整审计日志
- 为下游模块（分类、信号、知识库）提供信息可信度权重
- 评级规则可通过参数管理子系统热更新

---

## 2. 架构与流程

## 3. 数据库模型（PostgreSQL / SQLAlchemy）

```python
# backend/app/core/rating/models.py
from sqlalchemy import Column, Integer, String, Float, DateTime, ForeignKey, Enum, JSON, Text
from sqlalchemy.orm import relationship
from datetime import datetime
import enum

class ReliabilityRating(str, enum.Enum):
    A = "A"     # 官方权威
    B = "B"     # 正规媒体
    C = "C"     # 自媒体/财经网站
    D = "D"     # 待验证/低可信

class InfoRating(Base):
    __tablename__ = "info_ratings"

    id = Column(Integer, primary_key=True, autoincrement=True)
    info_id = Column(String(64), unique=True, nullable=False, comment="外部信息唯一ID (如URL hash)")
    source_url = Column(String(2048), comment="原始链接")
    source_domain = Column(String(255), comment="域名")
    title = Column(String(512))
    summary = Column(Text)
    publish_time = Column(DateTime)
    info_type = Column(String(32), default="news", comment="news/announcement/report")

    auto_rating = Column(Enum(ReliabilityRating), comment="自动评级")
    auto_confidence = Column(Float, comment="自动评级置信度")
    final_rating = Column(Enum(ReliabilityRating), comment="最终评级(人工可覆盖)")
    final_confidence = Column(Float)

    reviewed_by = Column(String(64), comment="最后人工审核人")
    review_comment = Column(String(512))
    review_time = Column(DateTime)

    created_at = Column(DateTime, default=datetime.utcnow)
    updated_at = Column(DateTime, default=datetime.utcnow, onupdate=datetime.utcnow)

class RatingAuditLog(Base):
    __tablename__ = "rating_audit_logs"
    id = Column(Integer, primary_key=True, autoincrement=True)
    rating_id = Column(Integer, ForeignKey("info_ratings.id"), nullable=False)
    operator = Column(String(64))
    action = Column(String(32), comment="change / override")
    old_rating = Column(Enum(ReliabilityRating))
    new_rating = Column(Enum(ReliabilityRating))
    comment = Column(String(512))
    timestamp = Column(DateTime, default=datetime.utcnow)
```

**说明**：
- `info_id` 可采用原文 URL 的 SHA256 前 16 位，确保去重。
- `auto_rating` 与 `final_rating` 分离，保留原始自动评级用于审计对比。

## 4. 核心类设计（参数化）

### 4.1 AutoRater

```python
# backend/app/core/rating/auto_rater.py
from app.core.params.service import ParameterService
from app.core.rating.models import ReliabilityRating

class AutoRater:
    def __init__(self, param_service: ParameterService):
        self.param_service = param_service
        # 从参数服务获取域名基础评级表（可热更新）
        self.source_ratings = self.param_service.get(
            "rating.source_base_rating",
            {
                "cninfo.com.cn": ("A", 1.0),
                "sse.com.cn": ("A", 1.0),
                "stcn.com": ("B", 0.9),
                "eastmoney.com": ("C", 0.6),
                "xueqiu.com": ("D", 0.2),
            }
        )
        # 作者历史准确率（可从数据库加载，此处简化使用参数默认值）
        self.author_accuracy = self.param_service.get("rating.author_accuracy", {})

    def rate(self, source_url: str, source_domain: str, author: str = None,
             info_type: str = "news") -> tuple[ReliabilityRating, float]:
        # 1. 基础域名评级
        domain_rating, base_confidence = self.source_ratings.get(
            source_domain, (ReliabilityRating.C, 0.5)
        )
        rating = ReliabilityRating(domain_rating)
        confidence = base_confidence

        # 2. 研报类型：根据作者历史准确率调整
        if info_type == "report" and author:
            author_acc = self.author_accuracy.get(author, 0.7)
            confidence = author_acc
            if author_acc < 0.5:
                rating = ReliabilityRating.C

        return rating, confidence
```

**参数化示例**：
- `rating.source_base_rating` 可在 Web 参数配置页面修改，实时调整域名评级。
- `rating.author_accuracy` 后续可通过分析师历史推荐准确率动态更新。

### 4.2 RatingManager

```python
# backend/app/core/rating/manager.py
from app.core.rating.models import InfoRating, RatingAuditLog
from app.core.rating.auto_rater import AutoRater
from app.core.database import SessionLocal
from typing import List, Optional

class RatingManager:
    def __init__(self, auto_rater: AutoRater):
        self.auto_rater = auto_rater

    def process_info(self, info_dict: dict) -> InfoRating:
        """处理一条信息，自动评级并存储"""
        with SessionLocal() as session:
            info_id = info_dict['info_id']
            existing = session.query(InfoRating).filter_by(info_id=info_id).first()
            if existing:
                return existing

            rating, confidence = self.auto_rater.rate(
                source_url=info_dict.get('source_url', ''),
                source_domain=info_dict.get('source_domain', ''),
                author=info_dict.get('author'),
                info_type=info_dict.get('info_type', 'news')
            )

            record = InfoRating(
                info_id=info_id,
                source_url=info_dict.get('source_url'),
                source_domain=info_dict.get('source_domain'),
                title=info_dict.get('title'),
                summary=info_dict.get('summary'),
                publish_time=info_dict.get('publish_time'),
                info_type=info_dict.get('info_type', 'news'),
                auto_rating=rating,
                auto_confidence=confidence,
                final_rating=rating,
                final_confidence=confidence
            )
            session.add(record)
            session.commit()
            return record

    def manual_override(self, info_id: str, operator: str,
                        new_rating: str, comment: str = "") -> InfoRating:
        with SessionLocal() as session:
            record = session.query(InfoRating).filter_by(info_id=info_id).first()
            if not record:
                raise ValueError("信息不存在")
            old_rating = record.final_rating
            record.final_rating = new_rating
            record.reviewed_by = operator
            record.review_comment = comment
            record.review_time = datetime.utcnow()

            audit = RatingAuditLog(
                rating_id=record.id,
                operator=operator,
                action="override",
                old_rating=old_rating,
                new_rating=new_rating,
                comment=comment
            )
            session.add(audit)
            session.commit()
            return record
```

## 6. Web 前端页面设计

### 6.1 评级审核页面 (`RatingReview.vue`)

| 区域 | 组件 | 说明 |
|------|------|------|
| 筛选条 | `el-select` + `el-date-picker` | 按评级、来源域名、日期过滤 |
| 待审核表格 | `el-table` | 展示标题、来源域名、自动评级、置信度，可多选 |
| 批量操作 | `el-button` + `el-dialog` | 批量修改等级，填写原因 |
| 单条审核 | 表格操作列按钮 | 弹出修改对话框，支持查看原文摘要 |
| 历史干预 | `el-tab-pane` 切换 | 查询人工修改记录 |

**交互流程**：
1. 页面加载，请求 `/rating/pending?rating=C`，默认展示自动评级为C和D的信息。
2. 管理员勾选多条，点击“批量修改至B”，弹出填写评论对话框，提交 `POST /rating/override`。
3. 表格中的评级实时更新（可前端直接修改 `final_rating` 显示）。
4. 切换到“干预历史”页签，查看 `audit-log` 数据。

## 7. 与下游模块的衔接

- **分类子系统**：根据信息的 `final_rating` 和 `final_confidence` 调整信号权重。例如，A级信息完全采纳，C级仅作参考。
- **NLP处理**：评级低的文本可不进行深度情感分析，节省算力。
- **知识库**：入库时增加可信度标签，检索时可过滤低质量文档。
- **信号生成**：若某股票近期利好消息来自D级来源，系统自动降权或不作为买入依据。
