## 模块概述

### 职责

- 统一封装多数据源（Tushare、AkShare、BaoStock），提供标准化的日线行情获取接口。
- 支持数据源的自动故障转移与健康检查。
- 将所有日线行情数据持久化到本地数据库（SQLite/PostgreSQL）。
- 提供数据查询、统计、手动补全等管理功能。
- 前端通过 API 查看数据概况、搜索特定股票数据区间、手动触发指定范围的行情采集。
- 后台定时任务自动进行每日行情采集，保证数据连续性。

### 支持的第三方数据源

| 数据源 | 类型 | 覆盖市场 | 费用 | 复权支持 |
|--------|------|----------|------|----------|
| **Tushare Pro** | 商业 | A股全品类 | 积分制 | 前复权 (`adj='qfq'`) |
| **AkShare** | 开源 | A股/港股/基金/期货 | 免费 | 前复权 (`adjust="qfq"`) |
| **BaoStock** | 开源 | A股 | 免费 | 前复权 (`adjustflag="2"`) |

##  后端架构设计

### 多数据源适配器

所有适配器必须实现 `DataSource` 抽象基类，提供以下核心方法：

- `fetch_daily_quote(symbols, trade_date) -> DataFrame`：获取前复权日线数据，返回统一字段。
- `get_all_symbols() -> List[str]`：获取全部股票代码。
- `check_health() -> bool`：健康检查。
- `get_source_name() -> str`：返回数据源名称。

**符号格式统一**：所有适配器内部归一化为 `代码.交易所` 格式（例如 `600000.SH`、`000001.SZ`）。  
**复权处理**：所有适配器均返回前复权价格，同时添加 `adj_factor` 列（暂时默认 `1.0`）。

####  抽象基类

```python
class DataSource(ABC):
    def __init__(self, param_service: ParameterService):
        self.param_service = param_service
    
    @abstractmethod
    def fetch_daily_quote(self, symbols: List[str], trade_date: date) -> pd.DataFrame:
        pass
    
    @abstractmethod
    def get_all_symbols(self) -> List[str]:
        pass
    
    @abstractmethod
    def check_health(self) -> bool:
        pass
```

####  具体适配器

每个数据源实现上述接口，内部调用各自 SDK（tushare, akshare 等），并负责将返回数据映射为系统标准字段。

### 数据源工厂与故障转移

使用 `DataSourceFactory` 根据参数服务中的主备配置动态创建适配器实例，并由 `FallbackDataSource` 封装主源与备用源的自动切换。

```python
class FallbackDataSource(DataSource):
    def fetch_daily_quote(self, symbols, trade_date):
        for source in [self.primary] + self.backups:
            if source.check_health():
                try: return source.fetch_daily_quote(symbols, trade_date)
                except: continue
        raise RuntimeError("所有数据源均不可用")
```

###  数据持久化

- **数据库**：开发环境默认使用 SQLite（`data/vinvest.db`），生产环境可切换至 PostgreSQL。
- **ORM 模型**：`DailyQuote` 表包含前复权价格、复权因子、数据来源与创建时间。
- **存储方式**：`DataStorage` 提供 `save_batch` 方法，采用了**纯原生 SQL** 来实现幂等插入使用原生 SQL来实现幂等插入，完全绕开了 SQLAlchemy 方言在参数化 `CURRENT_TIMESTAMP` 时的兼容性问题，也是当前生产代码中最稳定的方式。

### 数据调度器

`DataScheduler` 负责：

1. **定时采集**：每日盘后根据 cron 表达式自动获取当日行情。

2. **增量历史抓取**：首次启动时自动拉取最近 30 天历史数据。

3. **日志记录**：每次采集记录开始/结束时间、触发源、获取数量、入库数量、错误信息。

4. **手动补全**：支持对指定股票、指定日期范围进行按需采集。

   使用 APScheduler 管理定时任务，支持从参数服务读取 crontab 配置。

   ```python
   class DataScheduler:
       def __init__(self, data_source: FallbackDataSource, param_service: ParameterService):
           self.scheduler = BackgroundScheduler()
           self.data_source = data_source
           self.param_service = param_service
       
       def start(self):
           # 每日行情采集任务
           cron = self.param_service.get("data.market.cron", "30 15 * * 1-5")
           self.scheduler.add_job(func=self.fetch_daily_quotes, trigger='cron', cron=cron)
           # 新闻采集任务（每小时）
           self.scheduler.add_job(func=self.fetch_news, trigger='interval', hours=1)
           self.scheduler.start()
   ```

## API 设计

路由前缀统一使用 `/api/v1`

### 数据源状态与采集日志

**`GET /datasource/status`**  
返回主备数据源的健康状态与最后采集时间。

**`GET /datasource/logs?limit=20`**  
返回最近的采集日志（包含触发源、状态、记录数、错误信息等）。

**`POST /datasource/trigger/market`**  
手动触发当日行情采集（可选指定日期）。

### 行情数据管理

**`GET /data/summary`**  
返回数据库总体概况：总记录数、最早/最晚交易日期、覆盖股票数。

**`GET /data/range/{symbol}`**  
查询指定股票在本地数据库中的数据区间及记录条数。

**`POST /data/fetch`**  
手动对指定股票列表和时间范围进行行情补全。

## 4. 前端管理界面设计

### 4.1 数据管理页面 (`/data-management`)

页面划分为三大功能区域：

1. **数据总览卡片**：直观展示总记录数、覆盖股票数、最早/最晚日期。
2. **股票区间查询**：输入股票代码，立即查看该股本地存储的完整时间范围和记录数。
3. **手动补全行情**：支持输入多只股票（逗号分隔）、自由选择日期区间，一键触发采集，实时反馈结果。

### 组件结构

```
DataManagement.vue
├── 数据总览卡片 (el-row + el-card)
├── 证券区间查询 (el-card)
│   ├── 代码输入框 + 查询按钮
│   └── 结果显示
├── 手动补全 (el-card)
│   ├── 多股票输入 + 日期范围选择 + 触发按钮
│   └── 执行状态提示
└── 采集历史日志表格 (el-table)
```

所有后端 API 调用均使用 axios，并通过 Vite 代理转发到 FastAPI 后端。

## 数据库表完整定义

**表名**：`daily_quotes`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PRIMARY KEY AUTOINCREMENT | 自增主键 |
| symbol | VARCHAR(12) NOT NULL | 股票代码（标准格式如 600000.SH） |
| trade_date | DATE NOT NULL | 交易日期 |
| open | DECIMAL(15,4) | 开盘价（前复权） |
| high | DECIMAL(15,4) | 最高价（前复权） |
| low | DECIMAL(15,4) | 最低价（前复权） |
| close | DECIMAL(15,4) | 收盘价（前复权） |
| volume | DECIMAL(20,2) | 成交量（股） |
| amount | DECIMAL(20,2) | 成交额（元） |
| adj_factor | DECIMAL(15,6) DEFAULT 1.0 | 后复权因子 |
| source | VARCHAR(20) | 数据来源 (tushare/akshare/baostock) |
| created_at | TIMESTAMP DEFAULT CURRENT_TIMESTAMP | 记录创建时间 |

**约束与索引**：  
- `UNIQUE(symbol, trade_date)`  
- `INDEX idx_symbol ON daily_quotes(symbol)`  
- `INDEX idx_trade_date ON daily_quotes(trade_date)`
