## 1. 模块概述

### 1.1 职责

- 从多数据源获取A股核心财务报表数据（利润表、资产负债表、现金流量表）。
- 按季度粒度存储关键财务指标，支持历史追溯和增量更新。
- 提供财务数据查询、统计、手动补全等管理功能。
- 前端通过 API 查看数据概况、搜索特定股票的财务数据区间、手动触发指定范围的财报采集。

### 1.2 支持的第三方数据源

| 数据源          | 类型 | 覆盖市场  | 费用   | 备注                                     |
| --------------- | ---- | --------- | ------ | ---------------------------------------- |
| **Tushare Pro** | 商业 | A股全品类 | 积分制 | 接口齐全，需2000积分以上才能获取完整财报 |
| **AkShare**     | 开源 | A股       | 免费   | 提供利润表、资产负债表、主要指标         |

### 1.3 与行情子系统的关系

两个子系统**完全独立**，共享基础设施（参数服务、Redis、数据库连接），但各自有独立的适配器、调度器、API路由和前端页面。

### 2.1 财务数据适配器

所有适配器必须实现 `FinancialDataSource` 抽象基类。

#### 2.1.1 抽象基类定义

```python
class FinancialDataSource(ABC):
    def __init__(self, param_service: ParameterService):
        self.param_service = param_service

    @abstractmethod
    def fetch_income_statement(self, ts_code: str, period: str) -> pd.DataFrame:
        pass

    @abstractmethod
    def fetch_balance_sheet(self, ts_code: str, period: str) -> pd.DataFrame:
        pass

    @abstractmethod
    def fetch_cash_flow(self, ts_code: str, period: str) -> pd.DataFrame:
        pass

    @abstractmethod
    def fetch_financial_indicators(self, ts_code: str, period: str) -> pd.DataFrame:
        pass

    @abstractmethod
    def check_health(self) -> bool:
        pass

    @abstractmethod
    def get_source_name(self) -> str:
        pass
```

### 2.3 数据持久化

#### 2.3.1 ORM 模型定义（`backend/app/core/data/financial/models.py`）

from sqlalchemy import Column, Integer, String, Date, Numeric, DateTime, UniqueConstraint, Index, func
from sqlalchemy.orm import declarative_base

Base = declarative_base()

class IncomeStatement(Base):
    __tablename__ = "income_statements"
    id = Column(Integer, primary_key=True, autoincrement=True)
    symbol = Column(String(12), nullable=False, comment="股票代码")
    end_date = Column(Date, nullable=False, comment="报告期截止日")
    revenue = Column(Numeric(25, 4), comment="营业总收入")
    operating_cost = Column(Numeric(25, 4), comment="营业总成本")
    operating_profit = Column(Numeric(25, 4), comment="营业利润")
    net_profit = Column(Numeric(25, 4), comment="净利润")
    recurring_net_profit = Column(Numeric(25, 4), comment="扣非净利润")
    source = Column(String(20), comment="数据来源")
    created_at = Column(DateTime, default=func.now())
    __table_args__ = (UniqueConstraint("symbol", "end_date", name="uq_income_symbol_date"),)

class BalanceSheet(Base):
    __tablename__ = "balance_sheets"
    id = Column(Integer, primary_key=True, autoincrement=True)
    symbol = Column(String(12), nullable=False)
    end_date = Column(Date, nullable=False)
    total_assets = Column(Numeric(25, 4), comment="总资产")
    total_liabilities = Column(Numeric(25, 4), comment="总负债")
    total_equity = Column(Numeric(25, 4), comment="股东权益")
    cash_and_equivalents = Column(Numeric(25, 4), comment="货币资金")
    interest_bearing_debt = Column(Numeric(25, 4), comment="有息负债")
    source = Column(String(20))
    created_at = Column(DateTime, default=func.now())
    __table_args__ = (UniqueConstraint("symbol", "end_date", name="uq_balance_symbol_date"),)

class CashFlowStatement(Base):
    __tablename__ = "cash_flow_statements"
    id = Column(Integer, primary_key=True, autoincrement=True)
    symbol = Column(String(12), nullable=False)
    end_date = Column(Date, nullable=False)
    operating_cash_flow = Column(Numeric(25, 4), comment="经营活动现金流净额")
    free_cash_flow = Column(Numeric(25, 4), comment="自由现金流")
    source = Column(String(20))
    created_at = Column(DateTime, default=func.now())
    __table_args__ = (UniqueConstraint("symbol", "end_date", name="uq_cashflow_symbol_date"),)

class FinancialIndicator(Base):

#### 2.3.2 存储层（`backend/app/core/data/financial/storage.py`）

```python
class FinancialStorage:
    def __init__(self, database_url: str):
        self.engine = create_engine(database_url)
        Base.metadata.create_all(self.engine)
        self.Session = sessionmaker(bind=self.engine)

    def save_batch(self, model_class, df: pd.DataFrame, symbol: str, end_date: str, source: str) -> int:
        if df.empty:
            return 0
        session = self.Session()
        try:
            # 纯原生SQL upsert，保证跨方言兼容性
            table_name = model_class.__tablename__
            columns = [c.name for c in model_class.__table__.columns if c.name not in ('id', 'created_at')]
            placeholders = ", ".join([f":{col}" for col in columns])
            sql = f"""
            INSERT INTO {table_name} ({', '.join(columns)}, created_at)
            VALUES ({placeholders}, :created_at)
            ON CONFLICT (symbol, end_date) DO NOTHING
            """
            now = datetime.utcnow()
            count = 0
            for _, row in df.iterrows():
                params = {col: float(row[col]) if col in row and not pd.isna(row[col]) else None for col in columns}
                params['created_at'] = now
                session.execute(text(sql), params)
                count += 1
            session.commit()
            return count
        except Exception as e:
            session.rollback()
            raise e
        finally:
            session.close()
```

### 2.4 调度器设计（`backend/app/core/data/financial/scheduler.py`）

财务调度器采用**事件驱动**模式，而非定时任务：

```python
class FinancialScheduler:
    def __init__(self, data_source: FallbackFinancialDataSource, storage: FinancialStorage, param_service: ParameterService):
        self.data_source = data_source
        self.storage = storage
        self.param_service = param_service
        self._fetch_logs: List[Dict] = []

    def fetch_one_stock(self, symbol: str) -> dict:
        """获取单只股票最近6个季度的财务数据"""
        periods = self._get_recent_periods(6)
        results = {"income": 0, "balance": 0, "cashflow": 0, "indicator": 0}
        for period in periods:
            try:
                # 利润表
                df = self.data_source.fetch_income_statement(symbol, period)
                results["income"] += self.storage.save_batch(IncomeStatement, df, symbol, period, "tushare")
                # 资产负债表、现金流、指标同理...
            except Exception as e:
                logger.warning(f"{symbol} {period} 财务数据获取失败: {e}")
        return results

    def _get_recent_periods(self, n: int) -> List[str]:
        """生成最近 n 个财报期（如 20260331, 20251231 等）"""
        periods = []
        today = date.today()
        for i in range(n):
            # 往前推 i 个季度
            month = ((today.month - 1) // 3 - i) * 3 + 1
            year = today.year + (month - 1) // 12
            month = (month - 1) % 12 + 1
            periods.append(f"{year}{month:02d}01")
        return periods
```

## 3. API 设计

路由前缀：`/api/v1/financial`

| 方法 | 路径              | 说明                                                         |
| ---- | ----------------- | ------------------------------------------------------------ |
| GET  | `/summary`        | 返回财务数据总体概况（总记录数、覆盖股票数、最新/最老报告期） |

| GET  | `/logs`           | 获取最近财务数据采集日志                                     |

## 5. 数据库表完整定义

详见第 2.3.1 节 ORM 模型定义，核心表共 4 张：

- `income_statements`（利润表）
- `balance_sheets`（资产负债表）
- `cash_flow_statements`（现金流量表）
- `financial_indicators`（主要财务指标）

所有表均包含 `symbol` + `end_date` 唯一约束，支持幂等插入。
