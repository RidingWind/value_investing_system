## 1. 模块概述

### 1.1 职责
- 封装多数据源（免费/付费）接口，统一数据获取入口
- 自动进行数据源故障转移，保障数据可用性
- 定时采集日线行情、财务数据、新闻公告
- 提供手动触发采集与数据源状态监控接口
- 为上层业务模块提供标准化的行情、财务数据结构

### 1.2 支持的数据源

| 数据源 | 类型 | 覆盖市场 | 费用 |
|--------|------|----------|------|
| Tushare Pro | 商业 | A股全品类 | 积分制 |
| AkShare | 开源 | A股/港股/基金/期货 | 免费 |
| BaoStock | 开源 | A股 | 免费 |
| Efinance | 开源 | A股 | 免费 |
| yfinance | 开源 | 美股/港股 | 免费 |
| YahooQuery | 开源 | 美股/港股 | 免费 |

## 2. 后端架构设计

### 2.1 多数据源适配器

#### 2.1.1 抽象基类
```python
class DataSource(ABC):
    def __init__(self, param_service: ParameterService):
        self.param_service = param_service
    
    @abstractmethod
    def fetch_daily_quote(self, symbols: List[str], trade_date: date) -> pd.DataFrame:
        pass
    
    @abstractmethod
    def get_all_symbols(self) -> List[str]:
        pass
    
    @abstractmethod
    def check_health(self) -> bool:
        pass
```

#### 2.1.2 具体适配器
每个数据源实现上述接口，内部调用各自 SDK（tushare, akshare 等），并负责将返回数据映射为系统标准字段。

### 2.2 故障转移

使用 `FallbackDataSource` 打包主数据源与备用源：

```python
class FallbackDataSource(DataSource):
    def __init__(self, primary: DataSource, backups: List[DataSource]):
        self.primary = primary
        self.backups = backups
    
    def fetch_daily_quote(self, symbols, date):
        for source in [self.primary] + self.backups:
            if source.check_health():
                try:
                    return source.fetch_daily_quote(symbols, date)
                except Exception:
                    continue
        raise RuntimeError("所有数据源均不可用")
```

### 2.3 数据调度器

使用 APScheduler 管理定时任务，支持从参数服务读取 crontab 配置。

```python
class DataScheduler:
    def __init__(self, data_source: FallbackDataSource, param_service: ParameterService):
        self.scheduler = BackgroundScheduler()
        self.data_source = data_source
        self.param_service = param_service
    
    def start(self):
        # 每日行情采集任务
        cron = self.param_service.get("data.market.cron", "30 15 * * 1-5")
        self.scheduler.add_job(func=self.fetch_daily_quotes, trigger='cron', cron=cron)
        # 新闻采集任务（每小时）
        self.scheduler.add_job(func=self.fetch_news, trigger='interval', hours=1)
        self.scheduler.start()
```

### 2.5 API 设计

路由前缀：`/api/v1/datasource`

| 方法 | 路径 | 说明 |
|------|------|------|
| GET  | `/status` | 返回各数据源健康状态、最后采集时间 |
| POST | `/trigger/market` | 手动触发一次日线行情采集（可指定日期） |
| POST | `/trigger/news` | 手动触发一次新闻采集 |
| GET  | `/symbols` | 获取当前可用的股票列表（缓存） |

请求/响应示例：

```json
GET /status
{
  "primary": {"name": "tushare", "healthy": true, "last_fetch": "2026-04-26T15:30:05"},
  "backups": [
    {"name": "akshare", "healthy": true, "last_fetch": null}
  ]
}
```

## 3. 前端管理界面设计

### 3.1 数据源状态监控页

路由：`/datasource`  
组件：`DataSourceMonitor.vue`

功能：
- 显示各数据源名称、类型、健康状态（绿/黄/红）
- 最近一次采集时间
- 手动触发行情采集、新闻采集按钮
- 采集历史日志（最近10条）

### 3.2 页面组件结构

```
DataSourceMonitor.vue
├── 数据源状态卡片组 (el-row + el-col)
│   └── 每个卡片：名称、状态图标、最后采集时间
├── 手动操作区
│   ├── 触发行情采集按钮 (el-button + 日期选择器)
│   └── 触发新闻采集按钮
└── 采集日志表格 (el-table)
    └── 列：时间、数据源、操作、结果
```

核心数据获取：

```javascript
const loadStatus = async () => {
  const { data } = await axios.get('/api/v1/datasource/status')
  statusList.value = [data.primary, ...(data.backups || [])]
}
const triggerMarket = async (date) => {
  await axios.post('/api/v1/datasource/trigger/market', { date })
  ElMessage.success('已触发行情采集')
}
```
